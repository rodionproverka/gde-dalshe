# Где дальше

Адаптивный одностраничный каталог переезда для граждан РФ. Чистые HTML, CSS и JavaScript; сервер и сборка для публикации не требуются.

## Запуск

Требуется Node.js 22+ (зависимостей нет).

```sh
npm run dev
# http://localhost:4173
npm test
```

Также можно запустить любой статический HTTP-сервер из `dist/`. Открытие через `file://` не поддерживается из-за загрузки JSON.

## Что работает

- Фирменный стиль «Где дальше»: тёплая бумага, чернильный и терракотовый цвета, шрифты Cormorant и Manrope, мотив маршрута и визовых штампов, свой логотип (`dist/assets/logo.svg`) и набор иконок.
- Первый экран: «посадочный талон» для быстрого подбора (бюджет, число людей, срок в месяцах или годах, образ жизни) и колода фото городов.
- Готовые подборки: год без визы, у моря, виза номада, русскоязычные страны, метро и ТЦ, тропики.
- Фильтры: на десктопе — боковая панель, на телефоне — шторка снизу. Бюджет (доход или накопления), жильё, свой срок проживания с проверкой визовых маршрутов, типы виз, гражданство, образ жизни с режимом «все условия» или «хотя бы одно», регион, климат, язык, избранное. Активные фильтры видны чипами и снимаются в одно нажатие.
- Карточки: листание фото (наведением мыши или свайпом), визовый штамп, отметки совпадений, маршрут, который подходит по сроку.
- Страница страны: галерея из 5–10 фото на город с автопрокруткой и полноэкранным просмотром, вкладки городов, калькулятор срока и шкала маршрутов, подробные визовые маршруты (условия, документы, шаги, сборы), карта мест (ТЦ, аквапарки, парки аттракционов, зоопарки, музеи, достопримечательности) со списком, бюджет, цены, заметки о жизни, источники.
- USD / EUR / RUB, избранное в браузере, ссылки на страну (`#/georgia/georgia-0`).

## Границы исследования

Дата исследования: 30.10.2026. Проверены официальные правила въезда по 34 странам. Остальные направления — каталог для дальнейшего изучения, а не полная юридическая справка.

Реальные предложения аренды просмотрены по Алматы, Еревану, Бангкоку, Чиангмаю и Данангу. Наличие объектов не подтверждалось звонком. Бюджеты карточек **редакционные сценарии**, не средние рыночные цены; возможна погрешность больше 30%. Это явно подписано в интерфейсе. Цена отдельной квартиры не валидирует расчёт всего города.

Подробные товарные ориентиры Numbeo добавлены для Тбилиси, Белграда, Чиангмая, Бангкока, Еревана, Алматы, Лиссабона и Порту; для других городов прайс не выдумывается. Полные требования программ, персональное право подачи и налоговые последствия нужно исследовать отдельно. Отношение населения не оценивается необоснованными рейтингами.

Выбор «откуда» передаёт контекст в чек-лист страны; сайт не ищет рейсы и не проверяет доступность консульской подачи из каждой страны.

## Данные и обновления

- `dist/data.json` — каталог, сценарные бюджеты и юридические источники.
- `dist/research.json` / `research-sources.json` — первоначальные результаты исследования.
- `dist/gallery-extra.json`, `dist/places-extra.json` — дополнительные фото городов (Wikimedia Commons, с авторами и лицензиями) и места на карте (геопоиск Wikipedia). Обновляются командой `python3 scripts/enrich-media.py`.
- `dist/photos.json` — авторы, лицензии, исходные страницы и локальные пути фото. Изображения могут кадрироваться CSS.
- `dist/rates.json` — резервный снимок ExchangeRate-API с датой. В браузере запрашивается свежий курс; дата явно отображается.
- `scripts/seed.py` и `scripts/enrich.py` — воспроизведение начального набора данных. Затем `python3 scripts/apply-research.py` добавляет расширение по ещё 24 странам из `research/`. При редакторских изменениях правьте данные и генераторы согласованно.
- `dist/core.js` — расчёт и фильтры; `scripts/check.test.mjs` — 18 проверок существенных сценариев.

Внешние сервисы: Google Fonts, ExchangeRate-API; внешние ссылки — официальные ведомства, порталы, Google Maps. Аналитики и регистрации нет. Доход и накопления не включаются в URL; валюта, открытый город и остальные фильтры входят в ссылку.

## Публикация

GitHub Actions тестирует проект и публикует `dist/` в GitHub Pages после push в main. В Settings → Pages выбран Source: GitHub Actions. Для ручного запуска доступен workflow_dispatch.

Код приложения: MIT. Данные сторонних источников и фотографии сохраняют собственные условия использования. Атрибуция фотографий находится в `photos.json` и в карточках городов.
